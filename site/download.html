Check your download

Every release has a SHA256SUMS file, and each file above shows its SHA-256. Put the download and SHA256SUMS in one folder and compare:

  • Linux: sha256sum -c SHA256SUMS --ignore-missing
  • macOS: shasum -a 256 <file>, then compare with the matching line.
  • Windows (PowerShell): Get-FileHash <file>, then compare with the matching line.

To also check where a file was built, run gh attestation verify <file> --repo JorisJonkers-dev/rauls-trusty-toolbox (GitHub CLI 2.49 or newer, logged in with gh auth login). The packages themselves are not signed yet: Windows SmartScreen and macOS Gatekeeper will warn, and the steps above say how to go on. The install guide has the details.

Release notes

How raul updates

raul checks for a new release only when you ask: open the System page and choose Check again. If there is one, Update installs it and keeps the version before it, so you can go back. Nothing is downloaded in the background. You can also come back to this page and install a newer file over the old one.
