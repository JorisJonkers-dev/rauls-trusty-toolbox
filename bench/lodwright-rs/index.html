  • DynDOLOD: As above.
How it was measured

lodwright generate with all worlds with terrain; every result carries per-step wall time and the peak resident memory read after resetting the kernel high-water mark. Plain game: 18 plugins. Modded: 133 plugins. Default of at most four threads for terrain blocks. One run each, not a median.

Machine: 16 thread machine that other work was using at the same time (load average about 10); wall times vary by a third between runs of the same input

Source: https://github.com/JorisJonkers-dev/lodwright-rs/blob/main/docs/performance.md
