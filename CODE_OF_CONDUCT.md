# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space it runs: issues, pull requests, discussions and reviews.

In short: be respectful and constructive, assume good faith, and keep criticism about the work. Harassment,
personal attacks and discriminatory language are not accepted.

Report unacceptable behaviour privately to `security@jorisjonkers.dev`. Reports are handled by the maintainer,
confidentially. The maintainer may remove content, lock threads or block people who break this code.
