Features

What raul does, in one list. Items marked planned are in the demo but not in the current release; see Using the Toolbox for the difference.

Setup

  • Finds Fallout: New Vegas in Steam, GOG and Epic libraries.
  • Makes one storage folder for mods, profiles and downloads.
  • Never changes your game folder.

Mods

  • Installs mods from archives, including mods with an installer that asks questions.
  • Turns mods on and off, moves them, removes them, and undoes the last change.
  • Planned: a list of what is built into the engine, so you do not install it twice.
  • Planned: groups, drag and drop, search, and versions you can go back to.

Load order

  • Sorts with the LOOT masterlist and shows every move before it changes anything.
  • Planned: warns about a missing master on Home and in the sidebar.

LOD

  • Builds the distant land, objects and trees for exactly your mods.
  • Replaces the game's own far view with one that matches the world you walk through.
  • Planned: quality choices and fine-tuning.

Tale of Two Wastelands

  • Builds TTW from your own game copies and the installer file. Both games stay untouched.
  • Adds TTW as one mod you can turn on and off.

Playing

  • Starts the game on the nv-rs engine, which is built into raul.
  • Checks your setup first and says what is wrong.
  • Add-ons: small fixes raul makes on your computer for mods you installed, for example a smaller lamp glow. Turn one off and it stays off.

Testing (planned)

  • Stability test, benchmark, and location pictures with zoom.
  • Profiles, so you can try a change without losing a setup that works.
  • Doctor, which runs every check at once.

Everywhere

  • Linux, Windows and macOS, as native programs.
  • A command line for every page, with output scripts can read.
  • Benchmarks of raul itself, with a history.
  • Free software, GPL-3.0-only.
