Components

raul is made of five parts. Each has its own repository, its own tests and its own releases, and each works alone with its own command line.

Part What it does
nv-rs The game engine. A Rust port of Fallout: New Vegas, from slaterain. This is the project's fork of slaterain/nv-rs. raul starts the game on it.
nvmod-rs Mods. Instances, profiles, installing mods, conflicts and the load order list.
loot-rs Sorts the load order with the LOOT masterlist. It reads the list when it runs and does not copy it.
lodwright-rs Builds the distant terrain, objects and trees for your mods.
ttwright-rs Installs Tale of Two Wastelands from your own game copies. A rewrite of TTW_Linux_Installer.

Why separate

Each part does one job and can be tested alone. A part can be released when it is ready. raul links them into one program, and a raul release uses one set of versions that were tested together.

More

docs/COMPONENTS.md has the reasons and the origins in full, and docs/ARCHITECTURE.md shows how they fit together in the code.
